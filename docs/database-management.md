# 数据库管理（v0.1.3-rc.5）

数据库页面使用 MySQL、PostgreSQL、Redis 三标签，独立保留实例、搜索及分页。管理本机受管多版本实例及历史容器实例，不接管远程服务器。无对应软件时可跳转软件市场；实例异常保留列表并提供连接重试和实例设置。

## MySQL / PostgreSQL

- 每个实例内库名唯一，不同实例允许同名。创建库使用专用账号及本机来源，编码/排序规则由对应引擎校验。旧记录未保存编码时显示“待同步”，不会伪造实际值。
- 同步先扫描非系统库和账号关系，再选择纳管；重复纳管幂等，不创建或改写数据库、账号和授权。未知密码显示“未保存”，未发现库级账号关系的 MySQL 条目需先配置专用账号。
- 权限提供只读、读写、库内管理；展示实际授权。PostgreSQL 所有者固有权限不可降为只读，可创建或选用普通授权账号。其他角色继承和 PUBLIC 授权仍需核对实际授权；档位不会撤销其他数据库的权限。
- 账号密码与来源分别修改。共享账号改密更新所有关联记录；来源变更需要额外确认共享影响。远程来源须为 IP/CIDR，并经已有兼容 UFW 限源放行，保留非冲突 pg_hba.conf 规则。MySQL IPv6 仅单地址；IPv4 CIDR 按兼容 5.7 的 netmask 生成账号来源。
- 查看/复制业务密码需验证当前管理员密码，启用双因素时还需 TOTP。授权绑定当前会话五分钟；显示三十秒、关窗和切换实例清空。接口使用 POST、CSRF 和 no-store，审计不记录密码。连接信息默认不含密码。
- MySQL 表工具显示引擎、排序规则、估算行数、大小及备注，支持匹配版本 mysqldump 的结构导出、CHECK、OPTIMIZE；REPAIR 仅向 MyISAM/ARCHIVE/CSV 显示。
- PostgreSQL 显示各 schema 表、索引、大小及估算行数，使用 pg_dump 导出真实 DDL，支持 ANALYZE 和普通 VACUUM；不提供 VACUUM FULL。维护任务需确认对象和锁/负载影响。
- 备注仅写元数据；备份弹窗提供计划、立即执行、历史摘要、下载和新库恢复。SQL 导入从对应实例 imports 目录选择文件，由信任的管理员上传；导入内容及查询结果不进入通用任务日志。

## 删除、回收与恢复

先停止业务写入并确认维护窗口，再创建加密备份、校验 SHA-256、保存原关联/授权/到期记录，最后 DROP DATABASE。失败不继续删除；重启会检查已准备记录对应的真实数据库，绝不重放 DROP。账号默认全部保留，避免误删未登记的共享依赖。

专属备份保留三十天，不受普通备份保留数量影响。到期每小时检查并提交清理任务；实例不可连接时清理可延后。手动永久删除/清空须确认，仅处理当前实例的回收记录和对应专属备份，不删除业务数据库。执行器保留不含账号密码的最小清理标记，以便中断后协调元数据。

恢复默认新库与同名专用账号，生成随机密码，只开放本机，拒绝已有库/账号。目标须同引擎、同兼容分支（MySQL major.minor，PostgreSQL major）；不自动恢复整个角色清单。恢复验证覆盖表及行数，仍需应用验证；不能承诺在线写入零损失。源备份保留。MySQL 自动迁移仅 8.4 分支，PostgreSQL 仅同大版本且 public schema 的表；其他路径不标为可用。

## Redis

通过本机端口连接受管实例，支持逻辑库选择、SCAN 游标、名称匹配、类型筛选和去重加载更多，不显示伪造总数。SCAN 非快照，空批次且游标非零时仍可继续。

String、Hash、List、Set、Sorted Set 支持创建、查看、修改，集合支持指定成员/列表下标删除。支持保留 TTL 的值更新、TTL 调整、重命名（拒绝覆盖）及确认删除。保存使用 WATCH、DUMP 内容和绝对过期时间生成的修订校验，冲突返回 409，必须重新读取。

二进制用 Base64 明确展示。String 不超过 1 MiB 时完整读取后编辑；更大字符串分段 64 KiB 只读，防止片段覆盖。集合按约 100 项分段，单次编辑最多 1 MiB；超过 RESP 安全读取预算（4 MiB）的元素或键仅显示元信息并可下载，不能强行编辑。Stream 展示前 100 条只读内容。下载为 Redis DUMP 序列化，最大 2 GiB；没有任意 Redis 命令或清空库入口。删除键不可通过 SQL 回收站恢复。

实例快照备份及恢复复用已有流程，恢复目标必须是新的原生空实例；历史容器实例支持数据操作，容器快照暂未验证并在页面明确禁用。

## 验证范围

本地隔离容器测试覆盖 MySQL 5.7、8.4.8、PostgreSQL 18.0、Redis 7，原生客户端调用路径与历史 Docker 路径、实际只读/读写授权、非 public schema、备份失败不删库、回收恢复行数、Redis 五类型、二进制、大值、TTL 与修订冲突。原生路径的客户端工具由隔离容器执行，不能替代每个原生发行版和版本组合的部署验收。

发布工作流另跑 Linux 数据库集成、systemd 安装更新回退、HTTP/HTTPS 登录及实际发布二进制的侧栏导航。完整软件版本矩阵、生产规模和公网网络仍以项目验收文档为准。SQL 恢复当前最多 256 MiB、验证最多 1000 张表，表结构导出最多 2 MiB。
