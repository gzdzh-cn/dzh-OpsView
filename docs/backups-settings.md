# 备份与计划、面板设置（rc.17）

## 计划任务

“备份与计划”分为计划任务、备份记录、脚本库。导航先显示，各标签独立读取；表单采用固定头尾、中间滚动弹窗。

可用类型：Shell、Python、网站/数据库备份、目录备份、面板备份、HTTP 请求、网站日志切割、日志清理、证书续期、网站启停、时间同步。业务备份先在“备份记录 → 业务备份配置与存储”建立目标及存储配置，再在计划中多选。未提供木马扫描、数据库增量备份或默认清空内存。

周期为每天、每周、每月、间隔分钟或五段 Cron，最短一分钟；计划保存独立时区。更改面板默认时区只影响新计划；已有任务不改时区，停机错过的任务不补跑。执行历史独立留存，默认 30 天；同一计划不重叠，共享目标串行，冲突记录跳过。

脚本默认由专用 `opsview-task` 用户执行，可选已存在普通用户。Python 仅使用探测到的解释器，不安装依赖。root 脚本新增、启用或执行内容变化必须重新验证管理员密码及已启用的 TOTP；授权绑定内容摘要。复制、导入默认暂停，不继承 root 授权。脚本库使用独立加密修订；更新模板不影响已建立计划。

脚本在独立 systemd 临时服务中执行，使用真实退出码；超时或停止会结束整个控制组。默认超时一小时，可设置 60–86400 秒，不自动重试失败脚本。输出有大小上限，历史展示截断状态；已知私密变量会遮盖，但脚本本身也应避免输出业务凭据。脚本正文仅在显式编辑或导出时读取，不放入通用资源列表。

HTTP 任务使用 HTTP 客户端，支持 GET/POST、请求头、正文、超时和预期状态。默认 30 秒，最长五分钟；访问内网须显式允许，元数据、链路本地地址始终拒绝。每次连接校验并固定 DNS 结果，重定向重新校验且拒绝跨主机泄露凭据。

日志清理只处理指定日志目录中的普通 `.log/.log.gz`，不递归跟随链接；默认预览。日志切割复用安全重开流程，可按时间或大小、压缩和保留。

## 备份与恢复

默认新存储目录 `/www/backup`，历史备份保留原位置。修改默认目录不移动旧文件。网站和目录支持排除项及容量预检；文件在线副本不保证业务事务一致性。数据库使用对应引擎的逻辑备份；Redis 使用校验后的 RDB。

业务备份 `.ovb` 需要原执行器 `/var/lib/opsview/managed/backup.key`；面板 `.ovp` 需要原 `/var/lib/opsview/panel/master.key`。密钥不装入相应归档，须单独离线保管。缺少密钥明确拒绝恢复或完整性检查，不自动生成替代密钥。

面板、目录可复用已有业务备份配置中的 S3 存储。保留本地加密副本，上传成功后才执行旧成功备份的保留清理；上传失败保留上一份成功备份。目录、面板归档记录原 S3 配置版本，本地文件缺失时按受信任元数据取回并校验大小、摘要。下载、上传经认证入口及本机 Socket 流式传输，单次上传上限 2 GiB。不同 S3 服务商及灾难恢复仍须按实际环境演练。

备份记录统一展示对象、类型、状态、存储、大小、校验和时间。校验、恢复核对和删除进入任务中心，与恢复操作互斥。`.ovb` 上传须匹配本机加密历史；迁移归档前先恢复对应元数据，不信任任意侧车 JSON。旧 `.ovp` 可读，V2 包增加版本化清单、文件摘要和受管配置快照。

恢复网站、目录到新目录，数据库到新库/兼容实例，Redis 到空的新实例；拒绝覆盖已有对象。面板恢复只支持 OpsView 自身数据，不导入宝塔备份或整机迁移。

```bash
ov backup
ov restore --file /绝对路径/备份.ovp
# 核对新目录及相关软件依赖，再执行本机切换
ov restore --file /绝对路径/备份.ovp --switch
```

面板恢复先在新目录验证加密、清单、SQLite 和运行配置，再切换，失败恢复旧目录；API/临时令牌失效，所有计划暂停，核对后再启用。`managed-configs.json` 为受管配置及执行器状态的核对快照，不会自动覆盖现有实例配置、业务数据或执行器密钥。

## 六类设置

常用设置是面板、安全、界面和备份设置的快捷入口。分组更新携带修订号；并发修改返回 409，弹窗保留草稿。默认建站目录 `/www/wwwroot`、刷新 15 秒、会话八小时、备份七份。会话绝对期限与无操作超时分别设置，自动轮询不延长无操作期限。

“关闭面板网页入口”保留后台计划、续期和告警；本机健康检查保留。

```bash
ov panel off   # 仅关闭网页及外部管理 API
ov panel on
ov stop        # 停止整个面板服务，后台调度也停止
ov security status
ov security recover  # 显示影响并确认后恢复高级访问设置
```

安全设置包含管理员、密码策略、TOTP、会话撤销、域名/IP、安全入口、HTTPS、证书、BasicAuth、Passkey、客户端证书、临时只读授权和 API。高级功能默认关闭，不替代管理员认证。Passkey 需要匹配已配置的 HTTPS 域名、RP ID 和 Origin；地址变化可能影响凭据。客户端私钥只在生成时下载。临时授权一次兑换，十分钟，只读且可撤销；不允许读凭据、执行脚本或调整安全。

API 默认关闭，仅 HTTPS 请求头传递，保存令牌哈希，创建时显示一次；配置范围、来源和到期，逐次验证并独立审计。不可通过 API 绕过脚本 root 授权或敏感二次验证。地区限制使用本地 IPv4/IPv6 数据；先更新并验证当前来源，更新失败保留旧数据。访问变更使用 120 秒连接确认和超时回退。运行地址/IP 与高级认证恢复命令各有范围，按 `ov` 输出操作。

界面支持自动/浅色/深色、主题色、字号、菜单显隐和受控 PNG/JPEG/WebP 登录图片、favicon；可预览、导入导出和恢复默认。不接受任意 HTML/CSS；隐藏菜单不改变权限，设置与退出始终保留。

## 告警通知

告警分规则、通知渠道、发送记录。支持 SMTP（TLS/STARTTLS）、钉钉、飞书、企业微信、HTTPS Webhook，渠道凭据加密和遮盖，测试调用显示真实结果。

资源规则默认每分钟评估，连续三次触发，冷却十五分钟，可设置对象、阈值、静默窗口、恢复通知。任务、备份和异常登录事件即时入队。通知独立异步发送，最多三次尝试，发送失败不阻塞业务任务。通知只有摘要，不包含脚本正文、文件内容或业务凭据。机器人需要对应平台已配置且可访问的真实凭据；发布验证不向用户渠道发送消息。

## 升级与回退

rc.17 将 SQLite schema 4 增量升级至 5，保留账号、业务资源和计划 ID，增加独立历史、脚本修订、令牌与告警记录。安装器停服后先保存完整旧 panel 目录、运行配置、程序和 systemd 单元至 `/var/lib/opsview/updates/<时间>/`，再运行新程序迁移；升级失败自动恢复配套快照。

成功后回退 rc.16，必须停止服务，保存升级后现场，然后恢复**同一个升级前快照**中的 panel、bin、panel.json 和单元，再启动并验证登录及业务。禁止只换旧二进制读取 schema 5。备份快照含密钥，目录必须仅 root 可读；恢复面板元数据不能撤销已执行的脚本、数据库或系统配置变更。完整步骤见运维手册。
