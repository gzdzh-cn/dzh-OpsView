# OpsView v0.1.3-rc.27

完善网站列表、弹窗、创建结果和安全删除。

- PHP 列移到 SSL 前；三类项目增加局部刷新、勾选及批量删除，保留当前筛选分页。
- 创建改为单列表单，左右对齐；设置侧栏内缩、标签缩短，移动端标签置顶，弹窗固定头尾、中间滚动。
- 实际创建完成才关闭弹窗；创建中防重复，失败保留草稿并复用原站点和已建数据库。幂等标识及查询覆盖响应丢失，离开页面不取消后台任务。
- 单项与批量删除先预览逐站影响、等待 5 秒并确认。目录、数据库、日志默认保留；共享资源禁止随删，关联计划暂停，已有备份保留。
- 选中目录/日志进文件回收站，数据库先加密备份及校验后进入数据库回收站，保留 30 天。数据库维护须确认停止写入。
- 逐站记录步骤与结果，失败保留站点，支持核对中断现场；Nginx 删除校验/重载失败恢复原配置。数据回收与配置回退分别报告。
- 修复执行器空成功结果被省略后误报连接中断，增加明确终止标记，并兼容旧结果帧。

```bash
ov backup
ov update --version v0.1.3-rc.27
```

保持 SQLite schema 6，无新增迁移。回退使用此次更新的完整配套快照（程序、元数据、运行配置、单元），停止服务后恢复，不能只换二进制。主密钥独立保管；业务数据回收不会由元数据回退自动撤销。详见运维手册，实际验证及部署证据见验收记录。
