# OpsView v0.1.5

统一全站首次加载与重新登录显示，修复网站页退出后原路由登录时短暂误报“Nginx 未安装”。本版无新增后端接口或数据库迁移，保持 schema 6。

- 无有效数据时立即显示统一局部加载，标签导航及必要工具栏保持可见；接口成功后才显示空列表或安装引导。
- 复用登录时已核实的会话，主题与偏好独立读取；退出停止旧页面请求并清缓存，旧会话结果不能回写。
- 有效会话缓存即时展示，后台刷新失败保留内容并提供错误及重试；成功空数据也计为有效结果。
- 概览、网站、数据库、Docker、插件市场、文件、备份计划、系统安全、面板设置及任务中心统一接入，站点设置与独立标签读取互不阻塞。
- 文件工具栏及路径栏保留；设置读取成功前不显示默认值；SSH、防火墙、通知、Redis 等独立读取同步整改。

## 验证

前端 35 项单元测试、类型检查、生产构建及 83 项完整 Playwright 通过。覆盖同路由退出重登、两秒资源延迟、认证延迟、偏好阻塞、失败重试、真实空数据、旧会话隔离、亮暗主题与移动端。十个侧栏页面在框架出现后 200ms 内显示加载；本机缓存切页 20 样本 P95 为 69.1ms，实际网络耗时因环境而异。详见 [加载回归记录](../first-load-regression.md)。发布流水线另验 Go/race/vet、真实 Linux、实际二进制及安装更新回退，结果以验收记录为准。

## 安装与更新

```bash
curl -fL --retry 3 -o install_opsview.sh https://github.com/gzdzh-cn/dzh-OpsView/releases/latest/download/install.sh && bash install_opsview.sh
```

已有安装更新前保存元数据、运行配置与独立密钥，执行 `ov update`；固定版本使用 `ov update --version v0.1.5`。不重置账号、入口或业务数据，不自动整改旧项目权限或升级业务软件。

## 回退

更新器失败回退使用同次快照。需手动回退时先停止面板与执行器，配套恢复旧程序、面板数据库、执行器状态、运行配置、密钥及服务单元，再启动并核对健康状态、站点与文件归属；不以旧程序直接读取其他版本升级后的元数据。网站及数据库业务目录不覆盖。v0.1.4 的权限整改、运行隔离及账号生命周期约束继续适用，详见 [运维手册](../operations.md)。
