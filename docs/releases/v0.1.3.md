# OpsView v0.1.3

本版汇总至 `v0.1.3-rc.31` 的功能与修复，以正式 Release 发布并设为 GitHub latest。默认安装命令无需指定版本即可安装本版；已有面板可用 `ov update` 更新。安装器仍校验固定版本发布包的 SHA-256，不从开发分支安装。

- 网站采用统一设置入口，支持静态/PHP、反向代理及托管项目，完善域名、分类、数据库联建、创建幂等与受保护删除流程。
- 数据库提供 MySQL、PostgreSQL、Redis 三标签；插件市场统一列表及受管实例入口，Nginx 使用单实例版本替换。
- 文件管理统一路径栏、大小计算、行内备注、权限、剪切粘贴、右键菜单、归档及保护路径检查。
- 系统防火墙与 SSH 管理、备份计划、面板设置、HTTP 登录兼容及全站紧凑亮暗主题沿用此前修复。
- `ov` 两列菜单包含 **18. 卸载 OpsView**，也支持 `ov uninstall`。仅 root 可执行，显示实际清单后只接受小写 `y`；源码、网站文件、完整数据库数据和外部 Docker 资源保留，面板凭据与本地备份删除。具体范围见 [卸载说明](../uninstall.md)。
- 公开安装验收增加正式版不带 `--version` 的安装及更新，验证实际安装版本与 GitHub latest 一致。

## 安装与更新

以 root 执行：

```bash
curl -fL --retry 3 -o install_opsview.sh https://github.com/gzdzh-cn/dzh-OpsView/releases/latest/download/install.sh
bash install_opsview.sh
```

已有面板先验证备份及独立密钥，再更新：

```bash
ov backup
ov update
# 固定版本：ov update --version v0.1.3
```

新安装生成随机账号、密码和安全入口，保存终端显示的完整登录链接。卸载后重新安装会生成新面板，不自动恢复旧账号和业务关联；保留的数据需要核对后重新纳管。

## 验证与回退

v0.1.3 与 rc.31 保持 SQLite schema 6，无新增迁移。从更早版本更新会执行既有增量迁移；旧二进制回退必须同时恢复升级前的配套元数据、运行配置和服务单元，不能直接读取新 schema。卸载主动删除本机备份和密钥，更新快照无法代替卸载前独立保管的恢复材料。

此前 rc.31 已通过 Go/race/vet、前端单元及类型检查、生产构建、73 项浏览器及实际二进制复测、四系统防火墙、真实数据库、文件、SSH、systemd 安装更新回退及隔离卸载验收。本版重新经过发布流水线后才上传安装包；公开 latest 的无版本安装检查在发布后运行，结果记录于 GitHub Actions。

目标发布架构仍为 Linux amd64，系统为 Ubuntu 22.04/24.04、Debian 12/13。测试不表示所有环境与业务数据恢复场景都已覆盖；具体验证范围与限制见 [验收记录](../acceptance.md)。
