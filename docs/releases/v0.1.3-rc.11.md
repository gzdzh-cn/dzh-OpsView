# OpsView v0.1.3-rc.11

系统防火墙自动展示已有 UFW/firewalld 规则，无需先检测或同步；普通规则可直接修改、删除。

- 端口、IP、转发、地区四标签，搜索分页、真实计数、批量选择、备注及原始规则详情。
- 防火墙持久化开关、仅 Echo Request 的禁 Ping、本机/远程转发、来源限制与明确 MASQUERADE 选项。
- IPdeny IPv4/IPv6 国家 CIDR、每周任务更新、校验失败保留旧策略与原始版权。
- Fail2ban SSH/Nginx 认证失败防护、管理来源白名单、封禁记录和解封，仅维护 opsview-* jail。
- OpsView/宝塔格式导入预览、选择导出和差异同步；未知条件不静默丢弃。
- 稳定规则修订、外部冲突检查、串行安全事务、120 秒管理连接确认及持久化回退。
- 本机恢复：`ov firewall status`、`ov firewall rollback [--yes]`。

## 升级

```bash
ov backup
ov update --version v0.1.3-rc.11
```

本版为预发布，不自动更新现有服务器或业务软件。GitHub latest 入口继续指向正式版；安装测试版必须显式指定版本。

SQLite 升级到 schema 4，保留账号、资源及数据库关联规则。成功升级后降级 rc.10 必须停服并恢复升级前完整 panel 目录（含 SQLite 和 master.key）、旧二进制、单元及 panel.json；先处理 pending，关闭新版扩展并保留恢复现场。不能仅装旧二进制。完整步骤见仓库 docs/operations.md 的 rc.11 更新与回退章节。

## 安全限制与验证范围

UFW/firewalld 同时运行及无法无损表达的高级规则保持只读。firewalld 初始化集合/出站策略需运行与永久配置一致；发现外部 iptables 链时拒绝重载或启停，防止旧版本 firewalld 清空 Docker 等外部链，已有普通规则仍逐项管理。

地区允许不等于仅允许该地区；监听/放行不等于公网入站可达。远程转发要求正确路由和 IP forwarding；firewalld MASQUERADE 按来源/目标主机作用，可能覆盖同两端间其他流量。关闭面板管理的防火墙不代表外部软件过滤关闭。

流水线执行 Go race/vet、前端类型及构建、浏览器导航、四系统隔离网络 UFW/firewalld 测试、独立客户端转发/Ping/管理端口回退、真实 Fail2ban 日志封禁，以及实际发布包安装、登录、更新与故障回退。容器测试不替代整机重启、独立公网、云安全组及各 Docker 环境的最终验收。完整记录见 docs/acceptance.md。
