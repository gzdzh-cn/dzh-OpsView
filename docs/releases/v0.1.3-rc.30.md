# OpsView v0.1.3-rc.30

- 网站刷新按钮与搜索相邻，删除重复项目计数。
- 域名管理改为多行添加与绑定列表，支持独立/批量解除、新标签访问、泛域名、IP 和自定义 HTTP 端口。
- 设置导航分离子目录绑定、目录、访问限制、流量限制、伪静态、默认文档、配置文件、SSL、PHP、重定向、反向代理、防盗链、安全、日志、告警及其他设置；固定头尾与中间滚动适配亮暗主题和移动端。
- 结构化策略实际生成 Nginx 配置：目录 BasicAuth、IP/目录/后缀限制、并发及速率、路径重定向、局部代理、防盗链、Gzip、缓存、安全响应头、CORS 和客户端证书认证。
- BasicAuth 密码只保存哈希，列表返回遮盖值；客户端仅提交 CA 公共证书。保存使用修订校验和任务状态，检查、重载、探测失败保留原站点。保存成功留在当前设置菜单。
- 配置区展示实际配置、漂移与历史；写入仍使用受控参数。访问/错误日志独立读取；网站告警复用现有通知服务和真实探测。

宝塔内核防篡改、专业扫描属于独立插件，本版不伪造开关。文件配额、WebDAV、Tomcat/Composer 工具链及任意 Nginx 配置编辑不在本次已验证范围。各菜单映射和验收证据见 `docs/website-settings-rc30.md`。

更新前先备份并独立保管主密钥：

```bash
ov backup
ov update --version v0.1.3-rc.30
```

无数据库迁移，保持 schema 6。更新不主动重载业务网站或更换业务软件。回退停服后恢复同次更新快照中的程序、面板数据、运行配置和单元；元数据回退不会撤销后续主动修改的业务数据。具体流程见运维手册。


验收与上线（2026-11-21）：源码、候选包及发布流水线全部通过，73 项浏览器回归及发布二进制复测通过；公开安装更新验证通过。线上已在新备份独立恢复验证后更新至 rc.30，现有站点 HTTP 200、站点配置与加密元数据保持一致。详见网站设置验收记录。
