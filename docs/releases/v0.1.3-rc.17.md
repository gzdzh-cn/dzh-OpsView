# OpsView v0.1.3-rc.17

完善备份与计划、六类面板设置，保持紧凑列表和固定头尾弹窗。

- 计划任务、备份记录、脚本库三标签；独立执行历史、停止控制组、时区、未来五次执行、分类、复制及暂停导入。
- 增加低权限 Shell/Python、HTTP、目录/面板备份、日志轮转/清理、网站启停及时间同步；root 执行内容绑定重新验证授权。
- 统一加密归档的上传、下载、完整性检查及新目标恢复；支持现有 S3 存储、失败保留及原存储版本取回，V2 面板清单兼容旧格式。
- 常用、面板、安全、界面、告警通知、备份恢复六类设置；修订冲突、独立会话与闲置期限、关闭网页后后台继续运行。
- 增加 BasicAuth、Passkey、客户端证书、一次兑换只读授权、HTTPS 范围 API 凭据、主题与受控登录图片；访问变更保持 120 秒确认及回退。
- 增加 SMTP、钉钉、飞书、企业微信及 Webhook，资源持续阈值、事件失败、恢复、冷却和独立发送历史。
- 增加 `ov panel on|off`、`ov security status|recover`、`ov restore --file`；受管配置快照仅供核对，不覆盖现有实例。

```bash
ov backup
ov update --version v0.1.3-rc.17
```

本版迁移到 SQLite schema 5。更新前保存备份与独立主密钥。更新器在迁移前停服保存完整配套快照；失败自动回退。成功更新后若回退 rc.16，必须恢复同一升级前快照中的旧 panel 元数据、运行配置、程序及单元，不能让旧二进制读取 schema 5；已执行脚本和业务变更不随元数据回退撤销。

测试包不会自动更新任何服务器。功能、密钥条件、保留策略、S3 服务商及系统环境验收范围见 `docs/backups-settings.md`、`docs/operations.md` 和 `docs/acceptance.md`。
