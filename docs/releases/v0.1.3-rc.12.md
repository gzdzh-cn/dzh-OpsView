# OpsView v0.1.3-rc.12

修复迁移服务器残留宝塔 `IN_BT` 或 Fail2ban INPUT 链时，UFW 开关及普通端口规则操作被全部禁用的问题。

- 防火墙开关支持实际关闭、开启，保留已有规则与外部链；保留 120 秒重新连接确认和超时回退。
- 普通继承端口可直接编辑、删除，同时修改系统运行规则及持久化配置，无需检测、导入或同步。
- 修正 firewalld 普通端口附件被误判为服务附件、非管理端口也要求管理确认的问题；原生双栈端口保留明确的地址族选项。
- 分开显示开关限制和规则操作能力。独立 nftables 基链或 firewalld 外部链不会再把全部普通规则按钮一起锁住。
- 检查 UFW `MANAGE_BUILTINS=no`，拒绝可能清空外部链的配置，不自动改写系统设置。
- 管理端口删除弹窗收集来源和影响确认，默认显示服务器实际观察到的客户端地址；启停任务也提供日志入口。

```bash
ov backup
ov update --version v0.1.3-rc.12
```

本版为测试版，不自动更新用户服务器。SQLite 保持 schema 4。从 rc.10 或更旧版本升级仍遵循 rc.11 的完整元数据备份与恢复要求；只更换旧二进制不能降至 schema 3。

UFW 与 firewalld 同时运行、无法无损表达的高级规则，以及数据库授权关联规则仍需按对应入口处理。关闭 UFW 不关闭其他软件独立过滤或云安全组；外部 firewalld 链的重载保护继续生效。测试记录见 `docs/acceptance.md`，恢复步骤见 `docs/operations.md`。
