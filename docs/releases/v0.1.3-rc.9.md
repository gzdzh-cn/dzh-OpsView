# OpsView v0.1.3-rc.9

Linux amd64 预发布测试版，优化文件管理路径栏与行内操作。

- 路径输入与面包屑合为一行；点击目录名跳转，点击路径后方空白处编辑。失焦保留草稿，回车或“前往”才提交，未提交路径不会改变实际文件操作目标。失败保留原目录列表。
- 目录大小原位显示旋转等待及 B/KB/MB/GB/TB 结果，支持重新计算、失败重试和取消，不再弹出结果窗口。任务按完整路径关联，切换目录不更新错行；文件变更使相关缓存和晚到结果失效。
- 备注直接在单元格编辑，失焦或回车保存，Esc 取消；未变更不请求，清空移除，失败保留草稿，不刷新整张列表。中文输入法组合期间回车不触发提交。
- 保留文件权限检查、受保护路径限制、后台任务及现有搜索/压缩结果窗口；适配长路径、键盘操作和移动端。详细行为见运维手册。

更新：

```bash
ov backup
ov update --version v0.1.3-rc.9
```

SQLite schema 仍为 3，无新增迁移；已有账号、站点、数据库及已安装实例保留。更新失败沿用自动回退；成功后如需回退 rc.8，保留并恢复更新前完整面板快照和旧二进制，步骤见运维手册。

本次不会自动更新用户服务器或业务软件。测试版不替换默认 latest 正式安装入口；具体测试证据和剩余生产验收范围见验收记录。
