# OpsView v0.1.3-rc.1

Linux amd64 预发布测试版，统一列表和服务器文件管理，完善 Docker 检测及原生安装流程。

- 全站业务列表使用核心软件的逐行表格与分页，插件市场改为列表，端口和服务增加结构化字段及原始诊断。
- 文件管理开放服务器 `/`：路径/收藏/备注、分块续传（单文件 2 GiB）、Range 下载、10 MiB UTF-8 修订编辑、批量复制移动、ZIP/TAR.GZ、权限和 30 天回收站；执行器保护面板秘密、运行时目录和关键目录，内容不进日志。
- 应用进程功能下线。旧 `/apps` 跳转网站“其他项目”，历史记录、服务及文件保留；关联网站使用原上游，不再因到期停止旧进程；旧变更接口返回 410。
- Docker 先区分未安装/未启动/兼容/失败，再加载资源。通过 `/version` 协商 API 1.41–1.47，成功缓存 30 秒，变更请求不自动重放；Redis/Adminer 容器模板移入 Docker。
- 软件市场只新增原生实例，名称固定 `软件-准确版本`，同版本唯一占用。卸载保留数据及记录，明确清理记录后才能重装，历史重复实例保留管理。文案为“极速安装”和“编译安装”，缺少验证包显示原因。
- 首批六个准确版本 × Ubuntu 22.04/24.04、Debian 12/13 的 24 个极速安装组合全部通过真实 systemd/协议与独立干净系统复验，已开放安装。软件包固定于独立 Release `software-44057101979` 并校验 SHA-256；其他版本矩阵仍待验收。

以 root 更新：

```bash
ov backup
ov update --version v0.1.3-rc.1
```

首次测试安装：

```bash
curl -fL --retry 3 -o install_opsview.sh https://github.com/gzdzh-cn/dzh-OpsView/releases/download/v0.1.3-rc.1/install.sh
bash install_opsview.sh --version v0.1.3-rc.1
```

更新保留管理员和业务数据，包含 schema 1 → 2 迁移。失败自动恢复升级前快照；成功后降级需完整升级前面板目录及旧二进制，不能让旧程序直接打开新 schema。手动回退、文件边界和实际验证见安装教程与 docs/operations.md、docs/acceptance.md。

此版本保持 prerelease，不改变正式 latest，不自动更新用户服务器。
