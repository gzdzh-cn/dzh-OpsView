# OpsView v0.1.3-rc.8

Linux amd64 预发布测试版，统一插件市场并完成目录内其他 Nginx 版本安装。

- 合并核心软件与插件为同一“插件市场”列表，应用分类为全部、已安装、运行环境、免费应用、安全应用、Docker应用、专业版应用和企业版应用；仓库管理保持独立标签。
- “已安装”按真实实例列出各版本，提供设置与服务操作；移除底部重复实例区域。已占用准确版本隐藏安装，其他版本可继续选择。失去仓库条目的历史插件仍可查看状态和卸载。
- 分类保留搜索、分页与导航状态；图标操作有无障碍名称，窄屏分类自动换行。没有真实应用的分类显示空状态，无购买、授权或计费流程。
- Nginx 旧版使用固定 SHA-256 的私有 PCRE 8.45 静态依赖及上游镜像，不安装全局旧 PCRE。依赖许可证随极速包分发；构建兼容系统 OpenSSL，目标机极速安装不编译主软件。
- 原生安装先完成真实 systemd 服务和 HTTPS/HTTP2/正则重写检查，再在独立干净目标系统复验，之后才提升受信任目录。具体版本、系统结果与独立软件包见验收记录。

Nginx 全部 13 个目录版本均覆盖四系统：1.31.8、1.30.6、1.29.8、1.28.3、1.24.0、1.23.4、1.22.1、1.21.6、1.20.2、1.19.10、1.18.0、1.28.0、1.26.3。新增 48 个组合固定引用 `software-44268894751`，累计目录为 136 个极速、112 个编译组合；旧软件包与摘要保留。
