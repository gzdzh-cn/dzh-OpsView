# OpsView v0.1.3-rc.2

Linux amd64 预发布修复版，修正终端菜单关闭 SSL 的行为，保留 rc.1 的软件目录与业务功能。

- `ov` 菜单第 15 项改为“关闭 SSL 证书（切换 HTTP）”，直接调用 `ov ssl off`，不再只显示证书状态和命令帮助。
- 关闭前确认切换为 HTTP；证书文件保留。操作仍使用持久化访问事务，打印 HTTP 确认链接，120 秒内未通过新地址确认则自动恢复 HTTPS。
- 已经关闭 SSL 时再次执行会显示当前登录地址；保留 `ov ssl status|on|off|issue|renew` 子命令。
- 前端 JS/CSS 等静态资源支持 gzip 协商压缩；带构建指纹的资源使用浏览器缓存，首页及接口继续禁止缓存，降低慢速连接的加载等待。
- 增加真实终端菜单测试，覆盖取消、确认、HTTP 重新连接及登录、证书保留；继续执行完整发布与公开安装检查。

以 root 更新：

```bash
ov backup
ov update --version v0.1.3-rc.2
```

关闭 SSL：输入 `ov` 后选择 `15`，确认后在 120 秒内打开终端打印的完整 HTTP 链接。旧版本可执行 `ov ssl off` 使用相同流程。HTTP 使用明文连接，需要 HTTPS 时执行 `ov ssl on`，或为域名/公网 IP 申请受信任证书。

如果 HTTPS 无法打开，先用 `ov status` 确认服务，再检查证书信任、实际访问协议和防火墙。自签名证书可能被客户端拒绝，不能据此判断服务已停止。

更新保留管理员、业务数据及当前 HTTP/HTTPS 配置；失败自动恢复更新前快照。此版本为 prerelease，不改变正式 latest；不自动更新用户服务器。
