# OpsView v0.1.3-rc.26

完善网站创建、统一站点设置，以及文件权限和常用操作。

- 新建站点移除高级设置与 Nginx 选择；PHP 下拉提供静态，未安装 PHP 仍能建静态站。首个域名生成默认项目目录，手改后不再覆盖。
- 三类项目共用分类和可选 MySQL/PostgreSQL 联建数据库；资源及任务原子预留，重试复用成功数据库，不删除已创建业务数据。数据库凭据仅加密保存在数据库服务。
- 域名和“设置”打开同一固定高度弹窗，移除行内编辑按钮；合并域名、目录、运行环境、代理/进程、高级参数、安全和原有站点功能。修订冲突及应用失败保留草稿。
- 静态站统一位于 PHP 项目标签，新增 PHP 版本列；静态与 PHP 互切先验证并探测，静态模式拒绝 PHP 源码下载，关闭专属 FPM 及开机启动。
- 受管 Nginx 只允许一个实例；更换版本在现有 ID 内暂存、全站校验、切换并探测，失败回退。中断恢复日志与旧运行包受保护。历史多实例不自动停止或删除，合并清理前禁止新增和替换。
- 首次创建仅在文件不存在时写入响应式首页和 404 页，无外部依赖；普通静态站返回真正 404，显式 SPA 与代理错误行为保留。
- 文件权限矩阵和数字权限同步；用户、组独立选择；批量混合权限仅更改明确选项，递归先预览确认，外部文件变化拒绝覆盖。
- 统一文件右键、行内更多和工具栏动作；支持复制、剪切、粘贴、重命名、权限、归档、收藏、属性与回收站。菜单避开边缘并支持键盘；移动失败保留剪贴板，压缩解压采用固定高度表单。
