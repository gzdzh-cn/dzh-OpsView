# OpsView v0.1.3-rc.23

改进主题入口、设置编辑及终端管理，完善首次安装安全入口。

- 主题局部更新保留用户已设置的刷新周期，不将轮询重置为默认值。
- 概览右上角增加主题图标，下拉选择跟随系统、亮色、黑色；保存失败保留原选择，亮色侧栏使用浅灰蓝底。
- 隐藏面板名称、侧栏标题及界面设置标签；新旧后端写入接口拒绝修改名称。
- 点击设置当前值行内编辑，右侧保存；访问、证书、认证及凭据就地展开，切换标签清除秘密草稿。保留修订冲突提示、身份验证及访问变更的 120 秒确认回退。
- 修正告警子标签及工具栏布局，适配窄屏。
- 安全入口 Cookie 按 HTTP/HTTPS 分离，修复切换协议后旧 Secure Cookie 阻碍登录的问题，兼容已有入口。
- 默认登录只显示账号、密码；启用 TOTP 时密码验证通过后进入验证码步骤，未完成验证不创建会话。Passkey 附加验证保留。
- Linux 首次安装生成随机安全入口，终端显示完整登录链接；升级保留现有入口状态。
- `ov` 菜单改为两列，0 在首项；新增 16 开启并重新生成入口、17 关闭入口。`ov info` 显示入口链接、用户名和脱敏密码；关闭入口只输出成功。

```bash
ov backup
ov update --version v0.1.3-rc.23
```

本版保持 SQLite schema 5。升级前独立保管密钥；更新器保留完整配套回退快照。降级须一起恢复旧程序、运行配置和元数据，不能只替换二进制。线上更新按本次用户授权安排，验证记录见 `docs/acceptance.md`。

发布修订：修正依赖下载重试循环的结束符；产品功能及验收要求保持一致，rc.22 未发布或部署。
