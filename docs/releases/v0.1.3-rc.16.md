# OpsView v0.1.3-rc.16

统一菜单加载反馈并完善 SSH、备份与计划。

- 删除概览右上角任务图标及占位，保留 GitHub 入口与侧栏任务中心。
- 标签导航先显示，内容局部加载；移除全局骨架空白，Docker 检测期间不再闪出其他布局。
- SSH 支持受控启停、重启、停用 120 秒自动恢复、本机账号创建、改密、密码锁定及解锁。每次账号操作验证管理员和双因素，敏感信息不进入任务。只有面板创建且无运行进程的普通账号可删除，主目录保留。
- SSH 登录记录支持时间范围、来源、账号、认证方式和采样计数；复用 Fail2ban 防护与解封入口。公钥管理保持 root 公钥范围，不导出私钥。
- 备份展示目标、历史、下载、新目标恢复与执行日志；计划支持执行、暂停、复制、日志、真实下次执行时间、服务器时区、周期预设及结构化导入导出。导入与复制默认暂停，只支持备份和证书续期。

```bash
ov backup
ov update --version v0.1.3-rc.16
```

预发布测试版，SQLite schema 4，无新增数据库迁移。保留管理员及业务数据。公开 latest 仍为正式 Release，需指定测试版。更新失败自动回退；成功后回退需恢复更新前同一快照中的程序、运行配置与匹配元数据。主机安全变更独立管理，不能通过程序回退撤销。详见 `docs/operations.md`，验证证据见 `docs/acceptance.md`。
