# OpsView v0.1.3-rc.5

Linux amd64 预发布测试版：数据库 MySQL / PostgreSQL / Redis 三标签及管理功能。不会自动更新用户服务器，不改变正式 latest。

- 数据库页沿用紧凑标签和列表，按实例独立保存搜索/分页；提供安装引导、连接诊断和共用实例设置。
- MySQL/PostgreSQL 增加同步预览和幂等纳管、实际授权/权限档位、共享账号改密、连接来源、备注、备份历史及表工具。表结构使用匹配版本工具导出；InnoDB 不显示 REPAIR，PostgreSQL 提供普通 VACUUM/ANALYZE。
- 密码经管理员密码和已启用的 TOTP 验证后临时查看/复制。授权限当前会话五分钟，三十秒遮盖，关窗/切换清除，响应 no-store；不进入导航缓存、任务日志或审计内容。
- SQL 删库须确认停写维护窗口，先生成并校验加密备份，持久化恢复信息后再删除；回收站三十天保留、恢复为新库与随机密码专用账号。共享账号默认保留，旧接口不能绕过回收保护。
- Redis 提供 SCAN 游标、逻辑库、五种常见类型的二进制安全编辑、TTL、重命名和确认删除。WATCH 和内容/到期修订阻止过期写入；大键只读分段或下载 DUMP，Stream 前 100 条只读。没有任意命令和清空全库入口。
- SQLite schema 2 → 3，保留原资源 ID 和管理员，允许不同实例同名库，新增账号关联与回收记录。同步更新 OpenAPI、前端类型和中文操作说明。

以 root 更新：

```bash
ov backup
ov update --version v0.1.3-rc.5
```

更新器停服备份并检查两个服务和健康接口，失败自动回退。**成功升级后若需回到 rc.4，不能只替换二进制或直接降级**：必须恢复升级前完整 `panel/`（SQLite、WAL、master.key）、旧 `bin/`（含受控更新脚本）、单元和运行配置，保留当前现场及用户 drop-in。具体命令见 [运维手册](../operations.md#rc5-数据库迁移与回退)。业务数据变更不会因面板回退而撤销。

本地验证：Go race/vet、前端类型检查/构建及 7 项单元测试、16 项安装器检查、24 项 Playwright（含密码/回收/Redis/窄屏与菜单切换）。缓存菜单切换 P95 约 51ms。隔离容器集成覆盖 MySQL 5.7/8.4.8、PostgreSQL 18.0、Redis 7，包括原生客户端调用路径、Docker 路径、真实只读/读写、非 public schema、备份失败不删库、回收恢复及 Redis 大值/TTL 冲突。

发布工作流额外验证 Linux 数据库、systemd 安装/更新/故障回退、发布二进制导航与公开下载安装。原生发行版完整版本矩阵、生产规模及公网网络仍需按验收文档逐项验证，不能据此视为全部生产验收完成。

当前边界：SQL 恢复最多 256 MiB/验证 1000 张表；MySQL 迁移仅 8.4 分支，PostgreSQL 仅同大版本 public schema；Redis 单次编辑 1 MiB，超过安全预算的内容只读下载；容器 Redis 快照恢复未开放。详细说明见 [数据库管理](../database-management.md)。
