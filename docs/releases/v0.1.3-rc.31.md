- 卸载与安装更新共用维护锁；正常停止数据库，按归属和文件身份检查执行，不跟随链接或跨越未登记挂载；失败保留继续处理所需程序和进度。

详细范围、停止服务影响及密钥注意事项见 `docs/uninstall.md`。普通更新不执行卸载，线上服务器不会用来做卸载验收。

更新前先备份并独立保管主密钥：

```bash
ov backup
ov update --version v0.1.3-rc.31
```
