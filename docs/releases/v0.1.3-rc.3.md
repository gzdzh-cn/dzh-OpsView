# OpsView v0.1.3-rc.3

Linux amd64 登录修复版，解决关闭 SSL 后账号验证成功却回到登录页的问题。

- 原因：HTTPS 与 HTTP 使用同名会话 Cookie。浏览器保留旧 Secure Cookie 时，会拒绝 HTTP 响应覆盖它，导致新登录会话无法保存。
- HTTP 改用独立的 `opsview_session_http`；HTTPS 保留原有 `opsview_session` 及 Secure、HttpOnly 保护。会话读取、接口鉴权和退出按实际协议使用对应 Cookie。
- 登录后检查浏览器会话是否实际建立；Cookie 被禁用或拦截时明确提示，避免静默返回登录页。
- 增加带旧 Secure Cookie、使用非 localhost 域名的真实浏览器回归，验证登录、刷新与菜单操作；增加 Cookie 被拦截提示，以及 HTTP/HTTPS 鉴权和退出的单元测试。

以 root 更新：

```bash
ov backup
ov update --version v0.1.3-rc.3
```

更新保留管理员、密码、业务数据和当前 HTTP/HTTPS 配置。已有 HTTP 用户需要重新登录一次；无需重置密码或手动删除旧 HTTPS Cookie。

尚未更新时，可暂用无痕窗口访问当前 HTTP 地址，或清除面板站点的 Cookie 后重新登录。此版本为 prerelease，不改变正式 latest；不自动更新用户服务器。
