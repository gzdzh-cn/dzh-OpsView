# OpsView v0.1.3-rc.13

统一全站紧凑 UI，解决长表单、设置页及手机屏幕中弹窗操作区被挤出的布局问题。

- 网站、数据库、Docker、插件、文件、备份、SSH、防火墙及任务详情统一弹窗和控件样式。
- 弹窗采用公共固定高度，顶部标题及底部操作固定，中间内容独立滚动；短内容、错误提示与标签切换不再撑高弹窗。
- 软件与网站设置复用侧栏及内容布局，保存、确认及取消操作固定在底部，手机屏幕自动换行。
- 统一任务抽屉、确认与输入框，保留嵌套弹窗、Tab 焦点、Esc 取消和关闭行为。
- 集中维护桌面 16px、手机 12px 边距及紧凑控件尺寸，移除单页重复间距与介绍标题。
- 新增并扩展页面回归，覆盖长内容滚动、配置冲突、嵌套确认、焦点恢复及窄屏固定操作。

```bash
ov backup
ov update --version v0.1.3-rc.13
```

本版为预发布测试版，沿用 SQLite schema 4，保留已有管理员、业务数据、插件及系统规则。GitHub latest 默认安装入口保持使用正式 Release，测试版需显式指定版本。本次发布不自动更新现有服务器。

更新失败沿用安装器自动回退；成功后回退应恢复更新前同一快照中的程序、运行配置与匹配元数据。跨 schema 版本恢复要求见 `docs/operations.md`，测试范围及限制见 `docs/acceptance.md`。
