# OpsView v0.1.3-rc.7

Linux amd64 预发布测试版，完善软件市场操作和多版本原生安装；不自动更新服务器。

- 从网站、数据库等入口携带软件参数进入市场时，显示当前软件筛选，并提供带图标、底色的“显示全部软件”按钮。
- 核心软件按所选准确版本展示操作：已有实例时显示“已安装/已占用/安装异常/待清理”，隐藏重复安装按钮；选择其他未安装版本后仍可安装。保留同版本唯一占用及不同版本并存规则。
- 已安装插件只提供设置、检查、卸载；已登记的版本与仓库版本不同时显示升级。卸载后的插件可以重新安装；设置弹窗使用“保存设置”。
- 扩展 MySQL、PHP、Redis 原生安装矩阵。旧 PHP 的 ABI 依赖在私有目录低权限编译；MySQL 旧客户端的 ncurses/AIO 兼容库放在实例目录，不替换系统库。极速包在全新目标系统验证运行、重定位和常用内置扩展后才开放。
- 软件配方固定 HTTPS 来源及 SHA-256；下载、构建和服务启动持续输出真实日志。安装失败保留现场，不覆盖已有服务或数据。

更新：

```bash
ov backup
ov update --version v0.1.3-rc.7
```

更新面板不会自动安装或升级业务软件。SQLite schema 仍为 3，已有网站、数据库、管理员和安装实例保留。成功更新后的回退步骤及完整元数据恢复要求见 [运维手册](../operations.md)；更新失败沿用安装器自动回退。

版本范围、系统验收结果、独立软件包发布记录与面板发布状态见 [验收记录](../acceptance.md) 和根目录的软件管理实现说明。尚未通过验证的组合保持不可安装。
