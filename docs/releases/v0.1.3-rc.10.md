# OpsView v0.1.3-rc.10

Linux amd64 预发布测试版，在“系统与安全”完善防火墙和 SSH 管理，沿用紧凑布局。

- 防火墙提供 UFW 安装、启用及兼容检测，实际规则的来源、方向、策略、备注和归属列表，以及独立 Docker IPv4/IPv6 入站诊断。支持启用、关闭和重载；启用前按指定 IP/CIDR 放行实际 SSH 与面板端口，启停均需 120 秒内确认，否则恢复原状态及本次新增规则。
- 新增 SSH 管理标签，读取实际 OpenSSH 配置，支持多端口、密码/公钥认证、root 登录策略、认证次数、登录等待和保活参数。变更检查端口、修订和 sshd 配置，临时保留旧端口；管理员通过新设置实际登录后确认，才移除旧监听端口。
- SSH 与防火墙待确认记录持久化，执行器重启后继续超时回退；恢复失败显示原因并重试。外部配置变化阻止覆盖，回退保留冲突主配置供核对。系统已有规则和业务数据保留。
- 管理 root 标准 authorized_keys 的公钥指纹、导入和删除，拒绝私钥、重复公钥及删除最后一个公钥；提供终端会话、有限登录日志和现有 fail2ban sshd 状态诊断。
- 新操作沿用结构化执行器、会话/CSRF 校验、任务中心与审计；真实 SSH 端口纳入防误封保护。未知防火墙、socket 激活、自定义 SSH 启动参数和非标准公钥路径只提供诊断，不自动接管。

更新：

```bash
ov backup
ov update --version v0.1.3-rc.10
```

SQLite schema 仍为 3，无新增迁移。更新不会自动启用防火墙或修改 SSH；只有管理员显式提交才执行变更。云安全组需独立配置；SSH 全局设置仍受 Match、PAM 和账号策略影响。本次未增加网页终端、任意命令、root 密码重置、端口转发或地区封禁。

修改网络安全设置前保留现有 SSH 会话；待确认或回退失败时先恢复网络配置，再降级面板，避免旧执行器不识别待恢复记录。更新失败沿用自动回退；成功后如需退回 rc.9，需恢复更新前完整面板快照及旧二进制，见运维手册。

Go race/vet、前端类型/构建、Vitest、Playwright 和独立 Debian 12 的真实 SSH 登录、端口切换、UFW 及回退检查纳入验证。Ubuntu 及其他系统新增安全能力的集成矩阵仍待验收，详细范围和实际发布结果见验收记录及系统安全说明。

测试版使用固定版本更新，不替换默认 latest，不自动更新用户服务器或业务软件。
