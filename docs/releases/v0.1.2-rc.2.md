# OpsView v0.1.2-rc.2

Linux amd64 预发布修复版，包含 rc.1 的软件管理、网站和面板设置功能，修复更新后点击左侧菜单无响应的问题。

## 修复内容

- Go 嵌入前端构建时包含下划线开头的文件，修复 `_plugin-vue_export-helper-*.js` 未进入发布二进制、懒加载页面返回 404 的问题。此问题通过用户实际 Edge 页面和服务器 HTTP 请求复现，刷新页面无法补回缺失资源。
- 新增构建目录与内嵌资源逐文件完整性回归；旧规则下测试失败，修复后通过。
- 浏览器测试改为使用内嵌资源并逐个点击全部左侧菜单；发布和候选流程增加实际打包二进制的完整浏览器回归。

## 安装与更新

已有面板以 root 执行：

```bash
ov update --version v0.1.2-rc.2
```

更新完成后重新加载面板页面，再点击左侧菜单。

首次安装：

```bash
curl -fL --retry 3 -o install_opsview.sh https://github.com/gzdzh-cn/dzh-OpsView/releases/download/v0.1.2-rc.2/install.sh
bash install_opsview.sh --version v0.1.2-rc.2
```

更新保留管理员和业务数据。本次发布不自动更新现有服务器，latest 正式入口仍保持原版本。完整软件版本与系统矩阵、生产网络、证书及业务恢复等验收边界沿用 rc.1，详见 `docs/acceptance.md` 和根目录软件管理实现说明。
