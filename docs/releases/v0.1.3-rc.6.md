# OpsView v0.1.3-rc.6

Linux amd64 预发布测试版。此次完善网站创建与顶部管理入口，不自动更新服务器，不改变正式版 latest。

- PHP、其他项目、反向代理使用独立紧凑建站弹窗。域名支持每行一个；名称和根目录随首个域名生成，手动修改后不再被自动覆盖。
- 新 PHP、静态及托管项目默认部署至 `/www/wwwroot/首个域名`；支持选择该目录下的项目文件夹。非空目录需要勾选纳管，保留原文件；已有项目不能共享根目录。已有站点保留原目录，不自动搬迁。
- “其他项目”增加网站内 systemd 托管：执行文件、JSON 参数、非 root 用户、环境变量、端口、健康检查、开机启动及进程日志。不恢复独立应用进程菜单；历史外部应用不受新进程启停逻辑影响。
- 网站备份、运行目录、文件入口和 PHP 权限使用真实项目路径。新项目父目录须由 root 所有且不能由其他用户写入，禁止根目录链接和越界目录。
- 反代支持发送 Host；高级配置保留路径规则、多上游、WebSocket 和超时。首次创建可上传证书；建站后继续使用 SSL 设置申请免费证书。
- 顶部提供 Nginx 高级设置、网站统计、本机基础扫描、网站安全及 Nginx 启停/重载/重启；服务操作显示关联站点影响并确认后进入任务中心。
- 本机扫描检查证书、配置漂移、敏感条目及目录权限；不包含 CVE 数据库、代码审计或远程探测。网站安全支持安全响应头、同源 iframe 限制和 PHP 上传目录执行限制。

更新：

```bash
ov backup
ov update --version v0.1.3-rc.6
```

SQLite schema 仍为 3。更新失败由安装器恢复原程序与配置；成功更新后如需回退到 rc.5，先备份网站和元数据，处理本版新增托管项目，再恢复更新前完整面板元数据、程序和运行配置。不能仅降级二进制继续管理 `managed` 类型站点。详见 [网站管理说明](../website-management.md) 与 [运维手册](../operations.md#rc6-网站目录与进程托管)。

验证范围：Go race/vet、前端单元测试、类型检查与生产构建、26 项 Playwright、安装器检查；发布流程另在临时 Ubuntu 24.04 systemd 主机验证真实 Nginx/PHP、新根目录、独立应用进程、失败回退及到期停用，并使用发布二进制验证导航及公开安装。具体完成状态见验收记录。

当前边界：新站点使用原生 Nginx；已有容器 Nginx 不自动改挂载。域名不接受内嵌端口，使用所选 Nginx 入口端口。反代目标为 HTTP/HTTPS，不提供 Unix Socket 代理。未增加 FTP 服务、Git 自动构建、一键应用市场部署、远程漏洞扫描或商业 WAF。数据库在数据库菜单创建管理。
