# OpsView v0.1.3-rc.29

修复公网 HTTP 下建站报错，并补齐浏览器兼容、断线恢复及全站流程回归。

- 三类建站兼容缺少 `crypto.randomUUID` 的浏览器，通过安全随机数生成 UUID；不会强制切换 HTTPS，不使用弱随机数。
- 创建请求 ID 在当前标签页保存，刷新或断线后核对原任务；只保存不透明标识，不保存数据库密码、证书或表单。退出或会话失效时清理。
- 前后端只将真实未登记请求作为 404；查询故障、损坏记录和关联信息缺失不会触发重复创建。运行中的任务重新连接观察，不重复提交部署。
- 复制兼容 HTTP 和剪贴板权限拒绝；自动复制不可用时提供只读文本手动复制，不误报成功。Passkey 不支持时明确说明原因并保留密码登录。
- 连续任务查询失败后停止无限等待，保留后台任务并提示重新连接；关闭页面清理读取和 SSE。旧会话响应、过期凭据操作结果和旧任务日志不会覆盖新页面。
- 扩展非 localhost HTTP、HTTPS 部署浏览器检查和已有菜单业务回归；详见 [流程排查记录](../flow-audit-rc29.md)。

```bash
ov backup
ov update --version v0.1.3-rc.29
```

保持 SQLite schema 6，无新增数据库迁移。主密钥独立保管。回退必须停止面板及执行器，恢复同次更新快照中的程序、元数据、运行配置和单元；元数据回退不撤销已经执行的业务操作。已有管理员和业务数据保留。
