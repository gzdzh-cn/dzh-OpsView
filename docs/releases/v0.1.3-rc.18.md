# OpsView v0.1.3-rc.18

统一全站浅色与深色主题，改善侧栏、按钮和内容区域的搭配及文字可读性。

- 浅色使用白色侧栏与浅灰背景；深色使用蓝灰分层，共用蓝色主色及完整状态色阶。
- 统一按钮悬停、链接、选中行、表格、表单、弹窗、下拉、编辑器、日志和图表配色，消除深色页面的白色模块。
- 自定义主色按主题调整显示对比度，保留原始保存值；主题预览、取消及系统模式切换即时同步。
- 默认和恢复默认使用浅色；已有明确保存的主题选择保留。
- 修复设置加载期间迟到响应覆盖输入草稿的问题，保持固定头尾弹窗及紧凑布局。

```bash
ov backup
ov update --version v0.1.3-rc.18
```

本版保持 SQLite schema 5。从 rc.16 或更早版本升级仍执行 schema 5 迁移。升级前独立保管密钥；更新器保存完整回退快照，降级必须配套恢复旧程序、运行配置和元数据，不能只替换二进制。业务操作不随元数据回退撤销。

测试与部署证据见 `docs/acceptance.md`；公开测试包由 GitHub 流水线构建、验证及发布。
