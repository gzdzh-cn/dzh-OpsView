# OpsView v0.1.3-rc.28

修复网站删除倒计时可读性与旧删除残留服务阻塞。

- 删除确认等待期间采用清晰的中性背景和文字，适配亮暗主题及移动端；保留五秒倒计时、影响确认和禁用保护。
- 站点配置及执行器记录已缺失时，核验残留 PHP-FPM 服务的完整生成内容、站点 ID、原生 PHP 实例与覆盖文件。确认归属后可沿用删除预览和任务清理独立服务，避免误报“存在尚未登记的站点配置或服务”。
- 残留服务摘要参与删除预览校验，执行前再次检查。无法确认的服务、符号链接、自定义覆盖和未登记 vhost 保留，并明确提示冲突对象。
- 文件、数据库和日志仍默认保留，不自动删除业务数据；沿用回收站、逐站结果及中断恢复。

```bash
ov backup
ov update --version v0.1.3-rc.28
```

保持 SQLite schema 6，无新增迁移。回退须停止面板与执行器，恢复同次升级快照中的程序、元数据、运行配置及单元。元数据回退不会自动还原已回收业务数据；主密钥独立保管。详见运维手册，实际验证及部署结果见验收记录。
