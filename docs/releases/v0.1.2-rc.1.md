# OpsView v0.1.2-rc.1

Linux amd64 预发布测试版，集中交付软件管理、网站和面板设置增量。此版本不修改 latest 正式安装入口，不自动更新现有服务器或业务软件。

## 本次功能

- 软件市场逐行列表、图文详情、版本与安装方式选择；Nginx/MySQL/PHP/Redis 实例设置、配置修订、历史与失败回退。
- PHP/反向代理/其他项目三个网站列表；独立 FPM、流量、到期策略、证书及配置管理。
- 面板五类设置行、HTTP/HTTPS 开关、证书管理和 ov 命令；访问设置修改需在 120 秒内重新连接确认。
- 软件日志筛选、脱敏、下载及私有归档；Nginx 在线归档验证真实进程描述符，失败恢复。
- PHP Session 支持 files、受管 Redis、本机 memcached 和可选 SASL；候选真实读写、FPM 有效配置验证、失败回退及站点前缀隔离。

## 安装与更新

root 执行：

```bash
curl -fL --retry 3 -o install_opsview.sh https://github.com/gzdzh-cn/dzh-OpsView/releases/download/v0.1.2-rc.1/install.sh
bash install_opsview.sh --version v0.1.2-rc.1
```

已有安装先备份，再执行：

```bash
ov update --version v0.1.2-rc.1
```

## 验证范围与限制

最终功能提交已通过 Go race/vet、前端类型/构建/测试、11 个 Playwright、安装器检查、四系统包测试、面板 systemd 安装更新回退、真实 Nginx 轮转及 PHP/FPM/memcached/SASL 验证。发布工作流重新执行关键门槛，并在发布后验证公开安装和更新入口；具体运行结果见 Actions 和 `docs/acceptance.md`。

当前新增源码安装只开放 Nginx 1.30.6、PHP 8.4.27、Redis 8.10.3 在 Ubuntu 24.04 的已验证组合，其他组合保留验证门槛。memcached 服务需预先安装。28 版本与四系统的完整安装/扩展矩阵、PHP 上传与超时跨服务联动及 MySQL 完整大版本迁移仍待完善。公网证书、网络和业务恢复须按实际环境验收，此版本尚未作为完整生产首版交付。
