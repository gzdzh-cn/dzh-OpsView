# OpsView v0.1.3-rc.4

Linux amd64 预发布测试版：全站紧凑布局、菜单切换优化与受保护文件隐藏。

- 管理页面移除大标题、宣传文案、全局刷新和页脚；仅概览保留顶部右侧信息。侧栏底部提供账号菜单，窄屏保留导航按钮。
- 统一列表、设置行、文件工具栏和分页密度；Docker 可用时不显示版本/API/Compose 横幅，异常时仍可安装、启动和重试。
- 资源、任务、目录和概览独立加载；会话内缓存、合并重复请求、取消离开页面后的读取，阻止旧结果覆盖。按当前页面刷新，后台标签页暂停请求；软件目录缓存五分钟并在相关修改后失效。
- 保留各页标签、筛选、分页和滚动位置；退出清空会话缓存。图表、代码编辑器延迟加载，菜单悬停或聚焦预取页面代码。正文及密钥不进入共享导航缓存。
- 文件列表、搜索、属性、收藏、最近访问统一隐藏禁止访问项目和受保护别名，过滤后计算分页；可浏览的系统目录及普通隐藏文件保持可用。实际文件访问检查继续生效。
- `POST /api/v1/files` 的 `metadata` 操作支持 `recentPaths`（最多 15 项），返回已过滤的 `FileMetadata`；其他请求兼容，无数据库迁移。

以 root 更新：

```bash
ov backup
ov update --version v0.1.3-rc.4
```

保留管理员、密码、业务数据和当前 HTTP/HTTPS 配置。需要回到上一测试版时执行：

```bash
ov update --version v0.1.3-rc.3
```

安装器包含更新前备份、包校验、服务健康检查和失败回退。本版本保留 rc.3 的 HTTP/HTTPS 会话修复；不改变正式 latest，也不自动更新用户服务器。首次下载和服务器操作仍受网络与机器负载影响。

验证由发布工作流执行 Go race/vet、前端类型检查/构建/单元测试、浏览器登录和全部菜单回归、菜单切换延迟测量、Linux 文件及 systemd 安装/更新/回退，以及公开下载后的安装验证。公网业务软件完整验收边界继续以 `docs/acceptance.md` 为准。

本地验证：Go race/vet、7 项前端单元测试、16 项安装器检查和 22 项 Playwright 均通过；本机生产构建 20 次缓存菜单切换 P95 约 50ms。
