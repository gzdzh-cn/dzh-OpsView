# OpsView v0.1.3-rc.14

概览右上角新增 GitHub 图标，点击后在新标签页打开项目仓库。

- 与现有顶部栏保持紧凑样式，提供悬浮说明及键盘焦点提示。
- 手机端提供 44px 点击区域。
- 保留全站固定高度弹窗、固定头尾及内容区域滚动。

```bash
ov backup
ov update --version v0.1.3-rc.14
```

本版为预发布测试版，沿用 SQLite schema 4，无新增数据库迁移。保留已有管理员、业务数据、插件及系统规则。GitHub latest 默认入口仍使用正式 Release，测试版需显式指定版本。本次发布不自动更新现有服务器。

更新失败沿用安装器自动回退；成功后回退需恢复更新前同一快照中的程序、运行配置与匹配元数据，具体步骤见 `docs/operations.md`；测试证据及限制见 `docs/acceptance.md`。
