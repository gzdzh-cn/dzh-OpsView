# rc.29 全站流程排查记录

日期：2026-11-21。范围为当前已实现流程的源码核对、故障注入及回归，不表示整站不存在其他缺陷。生产业务不作为删除、安装、防火墙或恢复测试资源。

## 已修复

| 问题 | 处理与回归证据 |
|---|---|
| 公网 HTTP 建站调用不存在的 randomUUID | 原生 UUID 优先，缺失时使用 getRandomValues 生成 v4 UUID；安全随机数完全缺失时阻止提交。三类建站均有非 localhost HTTP 浏览器用例。 |
| 查询异常被当作不存在 | 前端只接受真实 404；后端区分未登记、解密失败和关联资源缺失。新增后端测试确保坏记录返回 500 且不创建站点。 |
| 刷新丢失建站请求标识 | 当前标签页 sessionStorage 仅保存不透明请求 ID；响应丢失、持续查询失败和刷新后复用原任务。成功及会话结束清除。 |
| 运行中任务恢复重复提交部署 | 再次提交前核对原请求状态，运行中继续观察；失败才进入原站点修正流程。保留已创建数据库。 |
| 查询中断无限转圈 | 每次任务读取设置十秒超时；连续五次失败提示重新连接，401/403/404 立即提示核对。仅停止观察，不取消后台任务。 |
| HTTP 剪贴板缺失及权限拒绝 | 统一现代剪贴板、兼容复制及只读手动选择。只有实际复制成功才提示成功；手动内容三十秒后或会话结束清理。 |
| Passkey 不可用但缺少解释 | 校验安全上下文和浏览器能力，在设置中展示原因，保留密码登录。 |
| 旧会话与旧页面结果污染 | API 丢弃前会话的迟到响应；凭据与客户端证书结果受组件生命周期约束；任务日志按选择序号隔离并处理坏帧。 |

相关新增测试：`web/src/lib/browser.test.ts`、`siteCreation.test.ts`、`siteTask.test.ts`、`web/tests/browser-compat.spec.ts` 及后端 `TestSiteCreationLookupDoesNotHideBrokenRecords`。已有创建失败修正、数据库联建与删除保护测试继续运行。

## 本地结果及限制

- 前端单元测试 27 项通过；类型检查及生产构建通过。
- 首次完整 Playwright 69 项通过；缓存切页 P95 为 67.2ms，低于 300ms 目标。最终提交与实际包结果由发布 CI 再核对。
- 安装器校验通过。最终静态资源冻结后，Go 全量 race 测试、vet 及嵌入资源一致性检查通过。检查时构建资源与嵌入资源验证不能并行修改同一输出目录。
- 本机为 macOS；systemd、防火墙、真实数据库及 Nginx/PHP 等 Linux 集成依赖隔离 CI，未在用户业务服务器上进行破坏性验证。
- 浏览器禁止 sessionStorage 时，仅保留页面内恢复；多个标签页不会共享建站请求。不支持的浏览器能力给出原因，不放松安全限制。
- 不新增数据库迁移；schema 6。生产验证不会读取或重置管理员密码，也不重建历史缺失站点配置。公开发布、Linux 验收与线上更新的最终证据追加至验收记录。
