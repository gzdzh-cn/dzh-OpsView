## 菜单映射与边界

| 宝塔菜单 | OpsView 实现 |
| --- | --- |
| 域名管理 | 多行输入、添加、独立/批量解除、主域名保护、端口及新标签链接；失败保留输入 |
| 子目录绑定 | 独立域名与子目录，显示实际绑定；拒绝目录跳转、隐藏项及链接 |
| 网站目录 | 根目录核对/文件管理、运行目录、访问日志；根目录不在此直接搬移；配额/WebDAV 未开放 |
| 访问限制 | 分目录 BasicAuth、目录/后缀禁止、IP/CIDR、HTTPS 客户端 CA 认证 |
| 流量限制 | 站点共享并发、单 IP 并发、请求 KB/s；不将这些指标描述为流量限额 |
| 伪静态 | 已验证的 PHP/静态路由模板；不开放任意 Nginx 指令注入 |
| 默认文档 | 多行有序文档列表 |
| 配置文件 | 真实配置、外部漂移及历史只读核对；受控高级参数编辑 |
| SSL | 原有证书上传、ACME 申请/续期和 HTTPS 跳转；不加入商业购买 |
| PHP | 实际版本/静态切换、独立 FPM/Session、可选 open_basedir、上传目录禁用 PHP |
| 重定向 | 精确/前缀路径、301/302/307/308、可选 404 跳转；不添加默认全站跳转 |
| 反向代理 | 代理项目与本地路径代理、多上游、Host、WebSocket、超时；不伪造代理正文缓存 |
| 防盗链 | 扩展名、允许域名、空来源及 403/404 响应；Referer 不能替代认证 |
| 防篡改 | 明确说明独立内核执行器依赖，保留备份入口；没有无效开关 |
| 网站安全 | 实际本机配置/证书/权限/常见敏感条目检查；非专业漏洞或恶意代码引擎 |
| 网站日志 | 独立访问/错误日志及局部刷新；不自动信任客户端 IP 转发头 |
| 网站告警 | 本站可用性和证书到期，复用通知渠道、分钟评估、持续/冷却/恢复；非另一个调度器 |
| 其他设置 | Gzip、静态浏览器缓存、安全响应头及 CORS；Composer/Tomcat 工具链未作为已实现功能提供 |

额外保留网站统计、到期时间、分类/备注、进程及备份。没有导入宝塔商业插件代码，没有添加虚假的成功状态。未开放项不计为已迁移完成。
